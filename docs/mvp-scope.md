# MVP Scope

## Must-have

### Platformadmin

- Login.
- Tenant aanmaken.
- Tenantstatus beheren.
- Tenantadmin uitnodigen.
- Schermlimieten instellen.
- Platformoverzicht met tenants, schermen en systeemstatus.

### Tenantadmin

- Dashboardoverzicht.
- Teamleden uitnodigen.
- Media uploaden.
- Media library bekijken.
- Playlist maken/bewerken.
- Playlist publiceren.
- Schermen aanmaken.
- Player koppelen via code.
- Schermstatus bekijken.

### Player

- PWA installable.
- Startup screen.
- Unpaired/pairing screen.
- Image/video playback loop.
- Local cache.
- Offline playback.
- Pending release download.
- Hash/checksum verificatie.
- Safe switch.
- Heartbeats.
- Diagnostics.

## MVP-media

Afbeeldingen:

- JPEG
- PNG
- WebP

Video:

- MP4 container
- H.264 video
- AAC audio
- standaard muted
- max 1080p player variant

## MVP-gecertificeerde player target

Kies één primaire target voor pilot:

- Chrome/Edge PWA op Windows of Linux mini-pc.

Andere platforms zijn later mogelijk maar niet gecertificeerd in de MVP.
